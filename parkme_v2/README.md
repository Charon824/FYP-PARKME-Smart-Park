# ParkMe — Complete Flutter + Firebase App

Full parking management app with Auth, Booking, and real-time Dashboard.

## Setup Steps

### 1. Firebase project
```
https://console.firebase.google.com → New project → ParkMe
Enable: Authentication, Realtime Database, Cloud Firestore
```

### 2. FlutterFire CLI
```bash
dart pub global activate flutterfire_cli
flutterfire configure
```
This creates `lib/firebase_options.dart`. The file is already imported in `main.dart`.

### 3. Install packages
```bash
flutter pub get
```

### 4. Firebase Realtime Database rules
Paste in Firebase Console → Realtime Database → Rules:
```json
{
  "rules": {
    "ParkingSlot": {
      ".read":  "auth != null",
      ".write": "auth != null"
    }
  }
}
```

### 5. Firestore rules (for user profiles)
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

### 6. Seed slots (first run only)
`ParkingService.instance.seedSlots()` is called automatically in `main()`.
It creates 5 slots only if the `ParkingSlot` node doesn't exist yet.

## How Sensors Connect

### Hardware (ESP8266 / ESP32 / Arduino)
Each parking slot has an IR or ultrasonic sensor connected to a microcontroller.

**Arduino/ESP32 code example (writes to Firebase):**
```cpp
#include <FirebaseESP32.h>

FirebaseData fbdo;
FirebaseAuth auth;
FirebaseConfig config;

void setup() {
  config.host  = "YOUR_PROJECT.firebaseio.com";
  config.signer.tokens.legacy_token = "YOUR_DATABASE_SECRET";
  Firebase.begin(&config, &auth);
}

void loop() {
  bool carPresent = digitalRead(IR_SENSOR_PIN) == LOW;
  String status = carPresent ? "Occupied" : "Available";

  Firebase.setString(fbdo, "/ParkingSlot/slot 1/Status", status);
  delay(2000);
}
```

### Flow
```
Sensor detects car
      ↓
ESP32 writes "Occupied" to Firebase Realtime DB
      ↓
Firebase streams change to all connected Flutter clients
      ↓
DashboardScreen updates in < 1 second via StreamBuilder
```

## Screen Navigation

```
Welcome → Login / SignUp → OTP (phone)
                  ↓
              MainShell (bottom nav)
            ┌────┼────┐
          Home  Book  Dashboard
```

- **Home** — live stats summary, quick actions, lot info  
- **Book** — reserve/cancel a slot with plate number, 15-min auto-cancel timer  
- **Dashboard** — real-time floor map, occupancy bar, per-slot sensor details, sync time
